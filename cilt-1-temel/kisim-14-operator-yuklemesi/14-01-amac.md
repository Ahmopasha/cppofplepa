## 14.1 Amaç

Operatör yüklemesi, kendi yazdığınız türlerin dilin operatörleriyle kullanılabilmesini
sağlar.

```cpp
Kesir a{1, 2}, b{1, 3};
Kesir c = a + b;          // operator+ yüklenmiş
std::cout << c;           // operator<< yüklenmiş
```

Amaç kurnazlık değil, **okunabilirliktir.** `a.topla(b)` yerine `a + b` yazabilmek,
yalnızca aritmetik anlamı gerçekten olan türler için doğrudur. Operatöre beklenmedik bir
anlam yüklemek, kodu kısaltır ama okunmaz hâle getirir.

## 4.1 `auto`

`auto`, değişkenin türünü ilk değer veren ifadeden çıkarmasını derleyiciye bırakır.

```cpp
auto x = 10;          // int
auto d = 3.14;        // double
auto s = "merhaba";   // const char*
```

İlk değer vermek zorunludur; çıkarılacak bir şey olmadan `auto` kullanılamaz.

```cpp
auto x;      // sentaks hatası
```

C ile aynı yazılan bu anahtar sözcüğün C'deki anlamıyla hiçbir ilgisi yoktur; C++11 ile
anlamı tamamen değiştirildi.
